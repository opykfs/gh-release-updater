## 关键工程信息

- 技术栈：Kotlin + Jetpack Compose + Material 3（Material You 动态取色、深浅色跟随系统）
- 构建：AGP 8.7.3 / Kotlin 2.0.21 / Gradle 8.9 / compileSdk 35 / minSdk 26 / Java 17
- 核心机制：PackageManager 读已装应用 → DataStore JSON 持久化绑定 → GitHub Releases API 比对版本 → DownloadManager 下载 → FileProvider + ACTION_VIEW 安装（含未知来源引导）
- 包名：`com.example.githubupdater`（FileProvider authority 同前缀）

## 下一步（用户操作）

1. **构建**：用 Android Studio（Ladybug+）打开工程根目录，Sync → Run ▶（或 `./gradlew assembleDebug`）。
2. **安装**：允许「安装未知应用」后安装 `app-debug.apk`。
3. **冒烟**：按 README「真机冒烟清单 A1–A6」逐条验证（重点 A4/A5 下载→安装链路）。
4. 首次构建若提示缺 wrapper jar，按 README 第 3 步由 Android Studio 自动生成。

## 范围外 / 已知限制

- 未做 GitHub Token 认证（未认证限流 60 次/小时，界面有提示）。
- 仅认 GitHub `latest` 正式 Release；不追踪 pre-release/draft；仓库需在 Release 附件中提供 `.apk`。
- 不做后台定时检测、不做下载断点续传、不做 APK 签名校验（个人工具定位）。
- 本环境无 Android SDK，代码未经真实编译；QA PASS 为静态审查结论，需在 Android Studio 完成首次构建与真机冒烟。
